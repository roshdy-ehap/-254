══════════════════════════════════════════════════════
  ميزان POS — تطبيق Electron
══════════════════════════════════════════════════════

📁 الملفات:
  main.js        — ملف Electron الرئيسي
  preload.js     — جسر الاتصال الآمن
  package.json   — إعدادات المشروع
  src/index.html — التطبيق الكامل
  build.bat      — بناء ملف التثبيت .exe
  run.bat        — تشغيل مباشر (للتطوير)

══════════════════════════════════════════════════════
🚀 تشغيل بدون بناء (للتجربة السريعة)
══════════════════════════════════════════════════════

1. ثبّت Node.js من: https://nodejs.org (اختر LTS)
2. انقر مرتين على: run.bat
3. انتظر تثبيت المتطلبات (مرة واحدة)
4. يفتح التطبيق تلقائياً

══════════════════════════════════════════════════════
📦 بناء ملف التثبيت للعميل
══════════════════════════════════════════════════════

1. ثبّت Node.js من: https://nodejs.org
2. انقر مرتين على: build.bat
3. انتظر 5-10 دقائق
4. الملف في مجلد: dist\
   - ميزان POS Setup.exe  ← للتثبيت عند العميل

══════════════════════════════════════════════════════
💾 البيانات
══════════════════════════════════════════════════════

البيانات تُحفظ في:
  C:\Users\<اسمك>\ميزان-بيانات\
    db.json              ← قاعدة البيانات
    نسخ-احتياطية\        ← النسخ التلقائية

لنقل البيانات لجهاز جديد:
  انسخ مجلد "ميزان-بيانات" كاملاً

══════════════════════════════════════════════════════

  Node.js 18+ (للبناء فقط)
  500 MB مساحة خالية على القرص
